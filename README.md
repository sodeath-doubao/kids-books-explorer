# Magical Book Explorer

This is a static HTML project that can be shared with one public GitHub Pages link.

## Publish on GitHub Pages

1. Create a new public repository on GitHub named `kids-books-explorer`.
2. Upload these files and folders to the repository:

```text
.github/
.nojekyll
index.html
kids_books_explorer.html
alpha-garchomp-cropped.jpg

```
3. Open the repository's **Settings** page.
4. Go to **Pages**.
5. Under **Build and deployment**, choose **GitHub Actions** as the source.
6. Wait for the `Deploy static site to GitHub Pages` workflow to finish.

After it deploys, the site will be available at:

```text
https://sodeath-doubao.github.io/kids-books-explorer/
```

Share that link instead of sending the HTML and image files.
